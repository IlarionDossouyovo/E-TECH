## Supplier Statuses
- VERIFIED: Confirmed official
- PARTIALLY VERIFIED: Some verification done
- UNVERIFIED: Not yet verified
- REJECTED: Failed verification

## API Endpoints
- GET /api/tv-suppliers - List suppliers
- GET /api/tv-suppliers/:id - Get supplier details
- POST /api/tv-suppliers/compare - Compare suppliers
- GET /api/tv-suppliers/brands/list - List covered brands
