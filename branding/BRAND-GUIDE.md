## Logo Usage Rules

### Minimum Sizes

| Format | Minimum Width |
|--------|--------------|
| Print | 25mm |
| Digital | 120px |
| Icon | 32px |

### Clear Space

Maintain clear space equal to 1/2 the logo height around all sides.

### Don'ts

- ❌ Don't stretch or compress the logo
- ❌ Don't change colors except using provided versions
- ❌ Don't add effects (shadows, glows) unless brand version
- ❌ Don't rotate the logo
- ❌ Don't place on busy backgrounds

---

## Brand Applications

### Website Header
Use transparent version or dark version on hero

### Social Media Profile
Use icon version (square, 500x500px)

### Business Cards
Use dark version on white stock, or light on dark

### Packaging
Use dark version with white text

### Billboards
Use main version with appropriate contrast

## Favicon Usage

- `E-Tech-Logo-Favicon.svg` for modern browsers
